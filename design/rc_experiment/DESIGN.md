# RC 扩增效应判定实验设计（DESIGN.md）

> 2026-09-28 起草。目标：在受控条件下测定反向互补（RC）扩增对三个规模模型的效应，回答"RC 对扩大的模型是否有用"。
> 前提事实：现有 52 runs 中唯一 RC 配对（small kmer6s6 @3e-4，Δ=0.0005 nats/base）落在 stride=6 退化区，**RC 效应目前不可估计**。

---

## 1. 核心设计陷阱：Tokens-seen 与 Unique-tokens 的混杂

RC-on 与 RC-off 的朴素 A/B 不是受控实验：RC-on 使一个 epoch 的 tokens 从 340M 变为 680M——**同时改变了 T（消耗的 tokens）和 D（见到的多样性）**。观察到"RC 更好"无法区分是"数据更多样"还是"单纯多训了一倍 tokens"。必须把两者解耦。

## 2. 三臂设计（Muennighoff 式解耦）

固定 T₂ = 2×T₁ = 680M tokens（约 1/2 epoch 的 2 倍），三臂只在"D 与 T 的组合方式"上不同：

| 臂 | 消耗 T | 唯一内容 D | 实现方式 | 隔离什么 |
|---|---|---|---|---|
| **A 基线** | 340M（T₁） | 340M | 原始链，1 epoch | 参照点 |
| **B 逐字重复** | 680M（T₂） | 340M | 原始链重复 2 遍（2 epochs） | B−A = 纯重复/算力效应（Muennighoff 的 R(D) 衰减） |
| **C RC 扩增** | 680M（T₂） | 680M | 原链+RC 链拼接，1 epoch | C−B = **变换重复 vs 逐字重复**（RC 的净效应）；C−A = RC 总效应 |

**C−B 是本实验的核心对比**：两臂 tokens 完全相同、原始碱基完全相同，唯一差别是第二遍以反向互补形式出现。若 C < B（loss 更低），RC 提供了逐字重复没有的可用多样性。

## 3. 规模交互：判别假设的关键（"对扩大的模型有用"的正解）

在 Chinchilla 框架下（D=340M → 最优参数 ≈17M）：tiny 8.4M 在最优以下（参数受限），small 85M 超 5×、large 0.95B 超 56×（数据受限递增）。三种假设给出不同预测：

| 假设 | 预测的 RC 效应模式 | 判别信号 |
|---|---|---|
| **数据受限**（F1 的诊断） | 效应随规模**递增**：tiny≈0 → small + → large ++ | C−B 随规模增长 |
| **熵受限**（可提取信号已耗尽） | 三规模全部 ≈0，Δ < 噪声 | C−B 与 B−A 全在噪声内 |
| **正则化效应**（类似数据增强降方差） | 三规模效应相近，不随规模系统变化 | C−B 平坦但显著 |

若结果是第一种，本实验同时**验证了 F1 的数据受限诊断**（用零成本干预证实瓶颈在数据侧）——与"预算应流向数据侧"的叙事闭环。这是设计此实验的最大叙事收益。

## 4. 协议细则

1. **Tokenizer**：per-base（旗舰配置）。注：RC 对 k-mer tokenizer 是更复杂的 token 空间变换（6-mer 的 RC 是另一个 6-mer），效应可能不同——留作后续扩展，不进本实验。
2. **LR**：固定为各规模已知最优——tiny 3e-4、small 1e-5、large 3e-5。风险：F4 已证明"排名是 LR 的函数"，RC 效应也可能依赖 LR；敏感性检查放 small 规模加一档 LR（可选）。
3. **不做 early-stop**：固定 T 全程跑完，在 {0.25, 0.5, 1.0}×T 设验证点，比较 matched-T 的 best-so-far 与 final——否则 early-stop 引入的选择偏置会污染臂间比较。
4. **Seeds**：每臂 ≥3 个随机种子（tiny/small），large ≥2 个。**Stage 0 必须先做种子方差 pilot**：取 small perbase 1e-5 现有配置跑 3 seeds 估 σ，据此定检测下限（n=3 时约 2σ/√3）。
5. **验证集协议**：验证集不施加 RC，仅原始链评估（确定性协议）；C 臂模型额外在 RC 链上评一次——两个方向的 loss 差本身就是"模型是否学到双链对称性"的独立测量，白送的观测。
6. **步数换算**（bs 口径）：tiny/small 16,384 tok/step → T₁=20.8k 步、T₂=41.5k 步；large 65,536 tok/step（4×4090 DDP）→ T₁=5.2k 步、T₂=10.4k 步。

## 5. 预算与分阶段执行

| 阶段 | 内容 | 机型与耗时 |
|---|---|---|
| Stage 0 | 种子方差 pilot：small perbase 1e-5 × 3 seeds（现有配置复跑） | ~3×1h |
| Stage 1 | tiny + small 三臂 × 3 seeds（18 runs） | tiny ~6h、small ~13h（215k / 100k tok/s 计） |
| Stage 2 | large 三臂 × 2 seeds（6 runs：3×6.7h + 3×13.5h） | 4×4090 约 **60h ≈ 2.5 天**（可排队穿插） |
| 合计 | 27 runs | 约 3–4 天机时 |

判别规模交互必须含 large（small→large 的效应增长是核心预测），Stage 2 不可省。

## 6. 结果解读矩阵

| 观测 | 结论 | 可否写简历/面试引用 |
|---|---|---|
| C−B<0 且随规模递增 | RC 扩增有效且效应随数据受限度增长；验证数据受限诊断 | ✅ "受控三臂实验证实 RC 保标签扩增的净效应" |
| C−B≈0，B−A>0 | 重复有收益但 RC 不优于逐字重复（变换无增益） | ✅ 诚实的 null 结果："RC 在该预算区无可检出净效应（上界 Δ<…）" |
| 全部 ≈0（<噪声） | 与熵受限一致 | ⚠️ 需配合高阶 Markov 基线才可下"熵受限"结论 |
| C−B 在 tiny 也显著 | 正则化解释（非数据侧） | ✅ 如实报告为 variance reduction |

## 7. 红线

- 效应量预期很小（plateau 区典型 0.001–0.01 nats/base）——**实验可能得出"无可检出效应"**，这是合法结果而非失败，报告为效应上界；
- 不因结果不显著而改协议、加臂数"挖到显著为止"；
- C 臂的 val 两个方向评估若差异大，说明模型未学到对称性，不影响主结论但须一并报告。
